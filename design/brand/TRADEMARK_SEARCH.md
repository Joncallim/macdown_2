# MostlyText trademark and name search record

**Owner summary.** This is a log of name and figurative-mark searches for
"MostlyText" and the Slant M+T mark. It records what was searched, where, when
and what was found. **It draws no legal-risk conclusion.** Whether any finding
matters legally is for a qualified trademark professional.

**As of 2026-09-27, both the word-mark and figurative (image) searches on all
three registers (WIPO, USPTO, IPOS) have been run manually, interactively.**
No exact or near-exact "MostlyText" / "Mostly Text" / "MarkText" word-mark
registration was found on any register, and no mark sharing the Slant mark's
specific M+T shared-stem, wedge-cut construction turned up in either
figurative search.

**One finding is flagged prominently for the owner and a qualified
reviewer, not resolved here:** IPOS's figurative search surfaced a live
Singapore registration for a stylised **"MT"** mark (Modern Tech Pte. Ltd.,
no. 40201616062P, class 9, expiry 2026-09-29) — see the search log's
2026-09-27 IPOS figurative-search row for the full record, image and goods
specification. It is a different construction from the Slant mark (upright,
no shared stem) and a narrow goods description (portable media players,
explicitly excluding communication functions) very different from a
downloadable text editor, but it is the closest same-letters, same-country,
same-broad-class live mark found across this entire screen and the expiry
date is imminent. **This screen does not conclude the mark is clear; it
surfaces this finding for a decision.** Two secondary items are also flagged
(MOSTLY AI, a live US/EU/UK software mark with a different second word; an
"MM" monogram in classes 9/42 with a loosely similar angular construction) —
see the log for details.

**Owner decision, 2026-09-27 (D-030, `design/DECISIONS.md`): Gate 4 is
HOLD, not closed, pending targeted legal review of the Modern Tech finding.**
No identity change is authorised on the strength of this screen alone.
Production design stays exactly as frozen at D-029.

## What to search

**Word marks**

| Query | Why |
|---|---|
| `MOSTLYTEXT` | The product name as one word |
| `MOSTLY TEXT`, `MOSTLY-TEXT` | Spaced and hyphenated forms |
| `MOSTLY*` in the classes below | Marks that start with the same word |
| `*TEXT` in the classes below, filtered for software | To catch close "…Text" editor names |
| `MARKTEXT`, `MARK TEXT` | An existing open-source Markdown editor with a similar name pattern |
| `MOSTLYTXT`, `MOSTLI TEXT` | Spelling and sound variants |

**Figurative mark:** the Slant M+T mark (`design/brand/slant/validation/slant-master.svg`,
exported as PNG for upload). Search it by image where the database supports
that, and by classification code:
- **Vienna classification** (WIPO, IPOS): category 27, "forms of writing".
  Choose the sections for letters in a special form and linked or overlapping
  letters in the database's own code picker when searching. They are not
  pre-selected here, to avoid recording an unchecked code.
- **USPTO design search codes:** category 27, "forms of writing"
  (https://tmdesigncodes.uspto.gov/category/27). Choose the stylised-letter and
  overlapping-letter sections in the manual when searching.
- Also search figuratively for single stylised **M** marks, to cover the
  BMW M perceptual neighbour noted in D-021.

**Classes (Nice classification):**
- **9:** downloadable computer software, text-editing software.
- **42:** software design and development, software as a service.
- Also record, without filtering to them, any hits in **35**, **38** and **41**
  that use the identical word.
