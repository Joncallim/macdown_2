# MostlyText design decision register

One line per decision: ID — decision — rationale — date / status.
Replaced decisions stay in the list and are marked `superseded by D-NNN`.

| ID | Decision | Rationale | Date / status |
|---|---|---|---|
| D-001 | Public name is **MostlyText** (casing `MostlyText`) | Owner decision; ships as a new editor descended from MacDown, not "MacDown 2" | 2026-09-25 · accepted (owner) |
| D-002 | The identity mark meaningfully combines **M** and **T** | Owner brand direction | 2026-09-25 · accepted (owner) |
| D-003 | Native macOS 26 conventions (Liquid Glass, system controls, native window tabs) are the default visual language; custom treatment needs a written reason | Matches E15 polish contract and the no-in-app-tab-bar rule in `AGENTS.md` | 2026-09-25 · accepted |
| D-004 | Design audits are grounded in screenshots of a Release build (`design/evidence/`), not inferred from Swift source | Debug builds feel different; the source does not show real rendering | 2026-09-25 · accepted |
| D-005 | The current app icon is a throwaway placeholder; the final icon does not need to resemble it | It was generated by script, not designed | 2026-09-25 · accepted |
| D-006 | Marks are judged in solid black on white before any colour; the blue-to-violet gradient is an application style, not part of the identity | Colour must not rescue weak geometry; the mark has to survive at 16 px and in one ink | 2026-09-25 · accepted (owner brief) |
| D-007 | Gen-2 finalists: **Crown** (M cut into a T: a symbol) and **Ligature** (M and T share a stem: a monogram). Arch's soft shoulders feed into Crown's refinement. Gate is dropped because its T doesn't read | Only these two show both letters without explanation; the choice between them is symbol versus typography | 2026-09-25 · superseded by D-008/D-009 |
| D-008 | Close the symmetric "crossbar with hanging arms + central stem" family (Crown, Arch, Gate) | Owner review: Crown reads as an IUD; all three share that outline, so refinement cannot fix it | 2026-09-25 · accepted (owner) |
| D-009 | Keep Ligature's shared M/T stem and give it energy through geometry first; colour is a two-tone accent on the T only. Gen-3 finalists: **Caret** (the T is a text cursor) and **Slant** (forward-leaning ligature) | Owner: Ligature needed more pop; Caret gets it from meaning, Slant from motion. Contrast fails at 16 px; Soft is kept in reserve | 2026-09-25 · resolved by D-010 |
| D-010 | **Slant** is the chosen identity direction: the M+T shared-stem ligature leaning forward, with an angled wedge cut on the crossbar. Two-tone colour goes on the T only | Owner choice over Caret: Slant has the most energy and is the most solid at small sizes | 2026-09-25 · accepted (owner); not frozen until the read test and similarity check pass |
| D-011 | Slant geometry: 12° lean, wedge cut, diagonals 15 / stems 17 (`design/brand/slant/marks.mjs`, variant `s12`) | 12° keeps the energy without reading as sport; thinner diagonals keep the V open at 16 px. The "upright wordmark" part of the original proposal is superseded by D-012 | 2026-09-25 · accepted (owner) |
| D-012 | The wordmark leans at the mark's exact 12°. Proposed: Inter Tight Bold (OFL, the SIL Open Font License), single colour; the two-tone "Text" version is kept for hero moments. The mark's letters stand about 1.15× the name's capital height. Final wordmark gets hand-corrected outlines | Owner choice to lean. A matched angle reads as intentional. SF Pro's licence doesn't allow use in a logo. At weight 800 the name competes with the mark | 2026-09-25 · accepted; construction refined by D-015 |
| D-013 | Canonical lockup: 12° Slant mark + leaned Inter Tight Bold wordmark, **single colour**. The two-tone "Text" wordmark is a secondary promotional treatment for later evaluation only; the identity must read fully without it. No further logo exploration; the lane is in pre-freeze validation | Owner decision: the mark already carries the energy, and a colour break inside the name adds a second device that reads as generic SaaS. The canonical system must survive in monochrome | 2026-09-25 · accepted (owner) |
| D-014 | Size-specific masters: `slant-16.svg` for ≤17 px, `slant-32.svg` for 18–40 px, the vector master above that; a separate simplified inner mark for the 16 px app icon. Horizontals snap to whole pixels, stems are whole pixels wide, diagonals are lighter, and the V is opened. 1-bit hand pixel grids are rejected | Scaled master loses the V and blurs at 16 px; stepped 1-bit grids break the 12° lean into a staircase | 2026-09-25 · accepted |
| D-015 | Lockup construction: wordmark = Inter Tight Bold **Italic** + 2.6° extra slant (12° total), not slanted upright letters; mark glyph 1.15× cap height standing on the baseline; 0.2 em gap measured along the lean; −2.5% tracking; clear space = crossbar height; minimum 12 px text, mark alone below that | The drawn italic keeps natural curves while matching the mark’s angle; baseline alignment makes the mark sit with the letters | 2026-09-25 · proposed for freeze |
| D-016 | Usage rule: never pair the mark with parallel stripes or a red-and-blue scheme; fallback if the read test or register search links it to BMW M is the 8° lean, not a new concept | BMW M is the one structurally close neighbour found; the rule keeps Slant clear of it | 2026-09-25 · accepted |
| D-017 | Freeze status: **geometry frozen** (D-011, D-014, D-015). Public identity freezes when four items close: (1) wordmark outlined with curve and "yT" corrections, (2) macOS icon set built in Icon Composer and checked in Dock and Finder, (3) human read test passes, (4) WIPO/USPTO register search is clear | No design defect remains; what remains is production work and external checks that can’t be done from this environment | 2026-09-25 · proposed, awaiting owner |
