MostlyText is released under the MIT licence. It continues MacDown, which is also MIT licensed, and keeps its original copyright lines.

MostlyText also includes third-party components, each under its own licence. The full notices ship inside the app (MostlyText › About MostlyText › Open Source Licences) and are listed for each release below.

Source code for each release

Some bundled components are licensed under terms that require their source code to be available when they're distributed. For each release, this archive keeps that source and our changes to it. The release's software bill of materials (SBOM) links every shipped component to its exact upstream revision.
