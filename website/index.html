A Markdown editor for the Mac.

MostlyText is a native macOS editor for Markdown and plain text. It's free and open source, and it continues MacDown under a new name.

Download for macOS

Version 1.0.0 · requires macOS 26 or later · signed and notarised by Apple

  • Works offline

    Opening, editing, preview, math, diagrams and export all run on your Mac. Your documents aren't sent to any service to be rendered.

  • Your files stay text

    Markdown stays plain text on disk. Previews and rendered diagrams are generated from it, never stored in its place.

  • Free and open source

    MIT licensed, like MacDown before it. The source, third-party licences and the source code those licences require are all public.

MostlyText is MIT licensed and descends from MacDown by Tzu-ping Chung and contributors.
